# Evidence matrix

The package exposes row-oriented Python APIs. The matrix covers the consolidation of the 0.3.0 baseline in version 0.4.0. Tests demonstrate the listed cases only. All test names below refer to the tests directory. Use python -m unittest discover -s tests -v with the optional dependencies installed. See docs/advanced.md for interface signatures and benchmarks/case_studies.py for the runnable research examples.

| Capability and objective | API and implementation | Scientific check and test | Evidence status and scope |
|---|---|---|---|
| Historical investable universe | market.audit_universe | historical_clocks, universe_includes_delisted; compare half-open effective intervals with knowledge intervals | Tested with synthetic membership ledger and case B. Stable IDs, known tickers and exit reasons depend on supplied history. |
| Corporate actions | market.audit_adjustment | corporate_actions, corporate_ledger; product of inverse split ratios and (P-D)/P | Tested with independent hand calculations. Requires attested completeness for PASS. Unsupported distributions require separate accounting. |
| Feature leakage | research.Lineage.check | control_evidence, feature_lineage_pipeline_and_backtest; parent and fitting clocks bound output availability | Tested on supplied graphs and case C. Numerical values cannot reveal unrecorded dependencies. |
| Backtest decision integrity | research.audit_backtest | control_evidence; FAIL dominates UNKNOWN, which dominates PASS | Tested without any trading threshold. Checks evidence, ordering and declared market/universe controls, not realized execution. |
| Time-aware validation | research.temporal_folds | validation_windows, fold_purging_and_embargo, snapshot_and_folds | Independently enumerated closed intervals. Rolling history bounds apply to training starts; embargo starts after the test label horizon. |
| Dataset versioning | research.dataset_version, compare_versions | manifest_types_and_report; hash sorted key-to-typed-value mappings | Reproducible fingerprints; semantic differences across format versions require rehashing original inputs. |
| Data lineage | research.Lineage.trace/check | control_evidence; directed acyclic dependency graph | Tested on unknown ancestors, cycles and timing conflicts. Transformation code and version identifiers must be supplied by the producer. |
| Release calendars | market.release_calendar | release_calendar, historical_clocks; choose maximal eligible announcement | Tested for rescheduling, cancellation and future realized clocks. Intraday times must come from source evidence. |
| Market sessions | market.MarketSessions | venues, exchange_holiday_and_early_close, sessions; half-open dated sessions | Tested on four venues and supplied intervals. Coverage concerns regular hours; liquidity and auctions require separate evidence. |
| Revision statistics | research.revision_statistics, revision_correlation | revision_statistics; sample variance, linear quantiles, Pearson correlation on matching timestamps | Analytic fixtures. Last supplied vintage is a reference, not truth. Sparse or constant samples can have undefined correlations. |
| Information sets | VintageIndex.asof/snapshot, research.information_set | randomized_panel_against_exhaustive_reference, snapshot_and_folds | Independent scans and future-invariance properties. Eligibility depends on clock policy and complete release evidence. |
| Provider consistency | research.compare_providers | cross_provider_and_batches; compare aligned eligible values using absolute plus relative tolerance | Tested on synthetic providers. Explicitly require metadata where its absence precludes comparison. No exchange-rate conversion. |
| Streaming data | large.audit_parquet, summarize_batches | three_parquet_backends, cross_batch_minimum; row-number and chronological-minimum oracle | One million synthetic decisions on five ingestion paths. Release index resides in memory. |
| ML pipeline auditing | research.audit_pipeline | control_evidence and ridge/scaler case C | Paired validation with fixed features, model and split. Fit and deployment metadata must describe the actual pipeline. |
| Scientific audit reports | research.scientific_report | manifest_types_and_report, dataset_and_report_reproducibility | Structured, JSON, CSV and escaped HTML; consistent hashes within the recorded environment. No regulatory certification. |
