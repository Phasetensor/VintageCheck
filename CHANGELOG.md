# Changelog

## 0.4.0 candidate

Separate public and operator information clocks, improve incomplete-evidence handling, add threshold-free decision auditing, typed fingerprints, revision statistics and portable scientific reports. Include million-decision ingestion comparisons and CurveMetric 1.5.0 integration evidence. Corporate-action ledger completeness and manifest version changes are documented in the advanced guide.

## 0.3.0

Add the fifteen research and market-data auditing capabilities documented in docs/advanced.md. Existing vintage audit entry points remain available.

## 0.2.0

- Add receipt-aware vintage lookup, historical snapshots and linked revision deltas.
- Classify decisions as PASS, FAIL or UNKNOWN and retain source evidence for both vintages.
- Import complete ALFRED observation histories with verified release clocks.
- Support DataFrame inputs, Parquet inputs and CSV decision reports.
- Add deterministic correctness and scaling experiments and a pandas comparison.

## 0.1.0

Initial threshold audit, historical GDP example, Python API and JSON command-line output.
